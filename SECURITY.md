# Security policy

## Supported versions
Only the latest release gets fixes. The plugin is in development (0.x).

## Reporting a vulnerability
Please **don't** open a public issue. Report it privately instead: on GitHub, go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the plugin and Obsidian versions. Please don't include real email content. Use made-up examples instead.

This plugin handles email, so reports about any of these are especially welcome:
- any way it could make a network request
- store email content it shouldn't
- read or delete files outside the drop folder
- weaken or get around the encryption of `records.json`
